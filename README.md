# The One-Liner Groan-Off

A program that writes a single original one-line dad joke to `entry.txt`:
"My calendar's days are numbered."

## How it works

`main.ts` (Node 22 stdlib only, no network) reads `MAKEFUN_OUTPUT_DIR`
(default `/output`), creates it if needed, and writes the one-liner —
32 characters, inside the bounty's 140-character cap — as UTF-8 bytes
with no trailing newline. It refuses to write a blank or over-long line.
